# Changelog

## 0.1.0

The first release of Sirius for VS Code.

- Sirius's own chat panel: Ask, Edit and Agent with the models you choose, their thinking shown as it streams — Anthropic's and Gemini's kept across tool calls and turns.
- Changes to files reviewed in VS Code's diff editor, or accepted as they come; tools that ask first; the open file, the selection, @-mentioned files, attachments and pictures as context.
- Tab completion from a code model on your own machine (Ollama or llama-server).
- Commit messages, from Source Control.
