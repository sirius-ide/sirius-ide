Sirius needs a model before the chat can answer. Everything else — the editor, extensions
from Open VSX, your settings — works without one.

<Steps>

1. **Install and open Sirius.** The [install guide](/docs/install/) covers every platform.
   The first start opens **Get started with Sirius**: seven short steps — connect a model,
   ask the agent, change code in place, project rules, Tab completion, importing from
   another editor, a theme — each with a button that does it. A step ticks itself off when
   it is done; *Connect a model* does as soon as any model is reachable. Reopen it any time
   from **Help: Welcome** or **Welcome: Open Walkthrough...**. The steps below are the same
   ground, by hand.

   :::note[Changed in 1.118.10]
   Earlier releases showed the editor's own welcome overlay first — *Welcome to VS Code*,
   with GitHub, Google and Apple sign-in buttons that do nothing for Sirius — and then a
   toast with **Set API Key** and **Select Model**.
   :::

2. **Give it a model** — one of two ways.

   **A provider key.** Open **Manage Models** — at the bottom of the chat's model picker
   (open *Other Models* if it is folded), or **Sirius: Manage Models** from the Command Palette
   (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>) — and choose **Add Models…**. Pick the
   provider — Anthropic, Google Gemini, OpenAI, OpenRouter, Groq, DeepSeek, Mistral or xAI —
   give it a name, and paste the key into the password box; it goes into the system keyring,
   never into settings.json. Sirius checks the key with one free request, and the provider's
   models appear at once; a rejected key shows as a red row saying so. **Sirius: Set API
   Key** does the same without opening the editor. [Providers and keys](/docs/providers/)
   has the rest.

   **Or a local model.** Install [Ollama](https://ollama.com), then:

   ```sh
   ollama serve          # if it is not already running as a service
   ollama pull qwen3     # any model you like
   ```

   Sirius looks for Ollama at `http://localhost:11434` and lists every model it finds —
   nothing to configure, no key, and nothing leaves your machine. See
   [Local models](/docs/local-models/) for LM Studio, llama.cpp and vLLM.

3. **Pick the model.** The chat's model picker, in the input, is the per-conversation
   choice. **Sirius: Select AI Model** sets the default — for commit messages, and for a
   chat that names no model: every model you have, by provider, with 🧠 for models that can
   reason and 👁️ for models that accept images. It becomes `sirius.ai.defaultProvider` and
   `sirius.ai.defaultModel`, the status bar shows **★ *model name***, and clicking that
   status item reopens the picker.

4. **Say what you want.** Open the chat with <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>I</kbd>
   (or **Sirius: Open AI Chat** from the Command Palette). **Sirius** is the default
   participant, so you type into the box that says *Describe what to build* and press
   Enter. The mode picker in the input switches between **Agent** (where it starts),
   **Ask** and **Edit** — see [Chat, edit and agent](/docs/chat-edit-agent/).

</Steps>

## If nothing answers

With neither a provider nor a running Ollama, the chat replies: *No model is available yet.
Add a provider and its key in **Manage Models** (the gear at the bottom of the model picker,
or **Sirius: Manage Models**), or start Ollama and pull a model — Sirius finds it
automatically.* A provider you have not added is not listed in the picker at all, and one
whose check failed shows its reason in Manage Models.
More cases are in [Troubleshooting](/docs/troubleshooting/).

## Thinking

Models that can reason (the Claude and Gemini models marked 🧠) reason by default.
**Sirius: Toggle Thinking Mode** turns it off
and on for the session's default; **Sirius: Set Thinking Effort Level** picks Low, Medium,
High, Extra High or Max. The status bar shows 🧠 beside the model name while thinking is on
for a model that supports it. Local and OpenAI-compatible models are not sent a thinking
parameter; if their server returns reasoning text, Sirius shows it.

## Defaults worth knowing

| Setting | Default |
| --- | --- |
| `sirius.ai.defaultProvider` | `anthropic` |
| `sirius.ai.defaultModel` | `claude-opus-5` |
| `sirius.ai.thinking.enabled` | `true` |
| `sirius.ai.thinking.effort` | `high` |
| `sirius.ai.maxTokens` | `16384` |
| `sirius.ai.temperature` | `0.7` |

The full list is on the [Settings](/docs/reference/settings/) page, generated from the
shipped manifest.
