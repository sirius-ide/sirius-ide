Open the Command Palette with <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>
(<kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> on macOS) and type *Sirius*. The identifiers
are what you bind in `keybindings.json`.

<CommandsTable />

The selection commands — explain, fix, write tests, refactor — also appear in the editor's
right-click menu when text is selected. The git commands run from the Source Control view
as well: the sparkle on the commit box and the merge-conflict action call them.
