---

Sirius needs a model before it can do anything. Add a provider key with
**Sirius: Set API Key**, or run models locally with Ollama and send nothing off your
machine. Then pick a model with <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd>.

:::note
The documentation is being written for 1.118.7. Until it lands here, the install
guide is [INSTALL.md](https://github.com/sirius-ide/sirius-ide/blob/sirius/INSTALL.md)
in the repository.
:::
