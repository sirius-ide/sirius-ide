Sirius IDE is a code editor built on Code - OSS with chat, inline edits, Tab completion and
an agent that works across your files — against the models you choose. It needs a model
before it can do anything: add a provider key with **Sirius: Set API Key**, or run models
locally with Ollama and send nothing off your machine. Then pick a model in the chat input,
or with **Sirius: Select AI Model**.
